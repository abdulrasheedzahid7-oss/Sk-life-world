# SK Life World

A browser-based 2D life simulation game. Start your character's story at age 10, explore a small town, manage daily needs, learn, play, and complete daily quests.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. No build tools or API keys are required.

## Controls
- Move with the arrow keys or WASD.
- On phones, use the on-screen directional pad.
- Select a location to travel.
- Choose Eat, Rest, Study, Play, Socialize, or Explore to advance time and change your character's stats.
- Use Save to store progress in this browser's local storage.

## Files
- `index.html` — game interface and panels
- `style.css` — responsive dark UI
- `game.js` — canvas scene, movement, simulation, actions, quests, and local save

## Current scope
This is the playable first version. Progress is stored locally in the browser. Online multiplayer, accounts, cloud saves, expanded age stages, and a larger world are not connected in this version yet.
